# OmniDimension UI Guide

Whenever a user asks how to configure a setting in the OmniDimension dashboard, or whenever you need to instruct a user on where to find a specific feature in the OmniDimension UI, you MUST follow these steps:

1. **Do not guess or assume UI locations** based on general knowledge of AI platforms.
2. **Search the Web:** Use the `search_web` tool with queries like `"OmniDimension" [Feature Name] docs` or search directly on `docs.omnidim.io`.
3. **Verify the Section:** Confirm the exact tab, button, or menu path (e.g., "Post-Call tab", "Voice Settings", "Knowledge Base") from the official documentation summary.
4. **Provide Exact Instructions:** Once verified, provide the user with the exact, step-by-step path to locate the feature.

## Common Locations (Reference)
- **Data Extraction / Webhooks:** Located in the **Post-Call** tab of the agent's configuration settings.
- **Knowledge Base:** Located in the Knowledge Base section (for uploading PDFs/documents).
